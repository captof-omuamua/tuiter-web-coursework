# Recovered coursework versions

The source bundle preserves HTML, CSS, Bootstrap, updated-HTML, and numbered-student-folder variants. Personal/uncertain-provenance images are replaced by neutral SVG placeholders. Team/student identifiers and local user paths are removed from publication copies. The peer-numbered archive is excluded.

The directly browsable version repairs missing local stylesheet references, image paths, and navigation case mismatches. Unimplemented action links remain historical placeholders. No social-network backend was recovered.
